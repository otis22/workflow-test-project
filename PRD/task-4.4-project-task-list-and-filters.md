# PRD: Task 4.4 Project task list and filters

## Goal

Turn the project workspace task section into the MVP project task list with server-rendered filtering by task status and deadline state.

## Acceptance Criteria

- The project workspace shows the project tasks as the main list for the stage.
- A project member can filter the task list by task status.
- A project member can filter the task list by deadline state.
- The filter controls are visible in the project workspace and can be reset.
- Automated tests cover the main task-list filtering paths.
