# PRD: Task 5.2 Task detail page

## Goal

Add a dedicated task page that becomes the main read view for a project task and prepares the UI structure for the upcoming commenting flow.

## Acceptance Criteria

- A project member can open a dedicated task page from the project workspace.
- The task page shows the main task fields: title, description, status, priority, assignee, due date, and project context.
- The task page provides navigation back to the project workspace and to the existing edit form.
- A non-member cannot open a task page for a project they do not belong to.
- The page includes a comments or activity section placeholder so the next commenting task can extend the same screen.
- Automated feature tests cover the main task-detail access and rendering paths.
