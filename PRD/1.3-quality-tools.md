# PRD: 1.3 Инструменты качества

## Цель

Подключить все обязательные инструменты качества из технических требований (секция 4).

## Инструменты

1. Laravel Pint — уже в composer.json (линтер/форматтер)
2. PHPStan — статический анализ
3. Rector — автоматический рефакторинг
4. PHPCPD — детектор копипасты
5. Infection — мутационное тестирование
6. composer audit — уже встроен в Composer

## Декомпозиция

### Подзадача 1.3.1: Установить PHPStan, Rector, PHPCPD, Infection

- `composer require --dev` для каждого пакета
- Создать базовые конфигурации

### Подзадача 1.3.2: Настроить конфигурации

- `phpstan.neon` — уровень 5+ для начала
- `rector.php` — базовый набор правил для Laravel
- `infection.json5` — конфигурация для domain/application слоёв
- Проверить что Pint работает из коробки

### Подзадача 1.3.3: Проверить все инструменты

- Запустить каждый инструмент и убедиться в отсутствии ошибок
