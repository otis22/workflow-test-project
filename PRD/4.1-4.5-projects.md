# PRD: 4.1–4.5 Проекты

## Цель

Реализовать CRUD проектов: миграции, use cases, UI.

## Декомпозиция

### 4.1 Миграции
- Таблица projects (id, owner_id, name, description, timestamps)
- Таблица project_members (id, project_id, user_id, created_at)

### 4.2 Use case: создание проекта
- CreateProject application service
- Автоматическое добавление владельца как участника

### 4.3 Use case: список проектов
- ListUserProjects — проекты где пользователь участник

### 4.4–4.5 UI
- Список проектов с кнопкой создания
- Форма создания проекта
