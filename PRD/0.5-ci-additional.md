# PRD: 0.5 — Дополнительные CI workflows

## Цель

Отдельные GitHub Actions workflows для задач, которые не должны быть в основном пайплайне:
- E2E tests (Dusk) — позже, в этапе 8
- Smoke tests (docker compose up + URL check)
- Mutation tests (Infection) — позже, в этапе 9

## Требования

- Каждый дополнительный workflow блокирует merge при неудаче (required status check в настройках репо — вне scope задачи)
- Smoke test: `docker compose up -d`, wait, `curl` на localhost:8080
- E2E и Infection — создать workflow-скелеты, помеченные как `workflow_dispatch` или отключённые до готовности (см. задачи 8.x, 9.x)

## Декомпозиция

### Подзадача 0.5.1: Smoke test workflow
- `.github/workflows/smoke.yml`
- Триггеры: `push` на main, `workflow_dispatch`
- Шаги: checkout → docker compose up → wait → curl check → docker compose down

### Подзадача 0.5.2: E2E workflow skeleton

- Только `workflow_dispatch` на этом этапе
- Комментарий: «Будет включён в задаче 8.1»
