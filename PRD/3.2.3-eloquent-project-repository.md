# PRD 3.2.3 — EloquentProjectRepository

## Источник
Roadmap 3.2 «Eloquent-модели и репозитории». Продолжает 3.2.2 (EloquentUserRepository).

## Контекст: архитектурный прецедент
3.2.2 зафиксировал паттерн, которому следует вся цепочка 3.2.x:
- Draft-паттерн: `save(Entity с id=0)` → insert, `save(Entity с id>0)` → update existing row.
- Отдельный `Mapper` класс с `toDomain(Model): Entity` и `toRow(Entity): array`.
- Update-ветка проверяет существование row и бросает `RuntimeException` при stale id.
- Feature-тесты через `RefreshDatabase` и `app(Repository::class)` (чтобы заодно проверить binding).

## Scope (этой подзадачи)

### `App\Infrastructure\Persistence\Eloquent\ProjectMapper`
- `toDomain(ProjectModel): Project`
- `toRow(Project): array<string, mixed>`
- Преобразование `owner_id ↔ ownerId`, `created_at/updated_at ↔ DateTimeImmutable`.

### `App\Infrastructure\Persistence\Eloquent\EloquentProjectRepository implements ProjectRepository`
- `findById(int $id): ?Project`
- `save(Project $project): Project` — draft-паттерн симметрично `EloquentUserRepository::save`.
- Инъекция `ProjectMapper`.

### Binding
Добавить в `PersistenceServiceProvider::register`:
```php
$this->app->bind(ProjectRepository::class, EloquentProjectRepository::class);
```

### Feature тесты
`tests/Feature/Infrastructure/Persistence/EloquentProjectRepositoryTest.php`:
- `it('saves a new domain project and returns entity with assigned id')`
- `it('finds a project by id, returning a domain entity')`
- `it('returns null from findById when project does not exist')`
- `it('updates an existing project and preserves createdAt while bumping updatedAt')`
- `it('throws when saving a project with a positive id that does not exist')`
- `it('preserves createdAt and updatedAt as DateTimeImmutable on round-trip')`

Фикстура: нужен user в БД для FK `projects.owner_id` (см. миграция 3.1 RESTRICT). Создаётся через `UserModel::factory()->create()` или raw insert.
