# PRD: 0.3 — Инструменты качества

## Цель

Установить и настроить инструменты качества кода из технических требований (секция 4):
- Pest (unit + coverage)
- Laravel Pint (форматтер)
- PHPStan (статический анализ)
- Rector (автоматический рефакторинг)
- PHPCPD (детектор копипасты, или совместимый аналог)
- Infection (мутационное тестирование)

## Требования

- Каждый инструмент запускается через composer-скрипт
- Все инструменты проходят на чистом проекте (baseline)
- Конфигурация инструментов зафиксирована в файлах (pint.json, phpstan.neon, rector.php, infection.json5)
- Команды документированы в README.md

## Декомпозиция

### Подзадача 0.3.1: Pest + Pint
- Удалить PHPUnit если есть, поставить Pest
- Установить Laravel Pint
- Скрипты: `composer test`, `composer format`, `composer format:check`

### Подзадача 0.3.2: PHPStan + Rector
- Установить PHPStan (larastan) + Rector
- Создать `phpstan.neon` (level 6), `rector.php`
- Скрипты: `composer stan`, `composer rector`, `composer rector:check`

### Подзадача 0.3.3: PHPCPD + Infection
- Установить детектор копипасты (sebastian/phpcpd или аналог)
- Установить Infection
- Создать `infection.json5`
- Скрипты: `composer cpd`, `composer infection`

### Подзадача 0.3.4: README команды
- Документировать все composer-скрипты в README.md
- Убедиться, что каждая команда запускается без ошибок
