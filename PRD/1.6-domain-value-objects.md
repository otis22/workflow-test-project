# PRD: 1.6 — Value Objects (Status, Priority, DueDate)

## Цель

Заменить строковые поля `status` и `priority` в Task на типизированные value objects. Добавить value object `DueDate` с доменной семантикой.

## Решения

- **Status** — backed enum `string`, кейсы: `Todo`, `InProgress`, `Done`. Идиоматичный PHP 8.1+, исчерпывающее покрытие через `match`.
- **Priority** — backed enum `string`, кейсы: `Low`, `Medium`, `High`.
- **DueDate** — final readonly value class, обёртка над `DateTimeImmutable`. Метод `isOverdue(DateTimeImmutable $now): bool`. Поле `value: DateTimeImmutable`. Конструктор валидирует, что dueDate не в прошлом относительно `createdAt`? Нет — дедлайн может ставиться задним числом. Просто хранит дату.
