# PRD: 0.1 — Docker Compose

## Цель

Создать Docker Compose конфигурацию для локальной разработки TaskFlow.

## Требования

- Три сервиса: app (PHP 8.3 + FPM), nginx (веб-сервер), db (PostgreSQL)
- `docker compose up` поднимается без ошибок
- PHP-контейнер содержит необходимые расширения для Laravel
- Nginx проксирует запросы к PHP-FPM
- PostgreSQL доступен из app-контейнера
- Volumes для кода (bind mount) и данных БД (named volume)

## Декомпозиция

### Подзадача 0.1.1: Dockerfile для PHP-приложения
- Dockerfile на базе php:8.3-fpm
- Установка расширений: pdo_pgsql, bcmath, mbstring, tokenizer, xml, ctype, json
- Установка Composer
- ~50 строк

### Подзадача 0.1.2: Конфигурация Nginx
- nginx.conf для проксирования к PHP-FPM
- Обслуживание статики из public/
- ~30 строк

### Подзадача 0.1.3: docker-compose.yml
- Сервисы: app, nginx, db
- Сети, volumes, порты
- Переменные окружения для PostgreSQL
- ~50 строк

### Подзадача 0.1.4: Проверка работоспособности
- `docker compose up --build` без ошибок
- Все сервисы healthy
