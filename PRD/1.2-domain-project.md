# PRD: 1.2 — Доменная сущность Project

## Цель

Создать чистый доменный класс Project в `app/Domain/Project/Project.php` — без зависимостей от Laravel/Eloquent.

## Поля

- `id: int`
- `ownerId: int`
- `name: string`
- `description: string` (может быть пустой строкой)
- `createdAt: DateTimeImmutable`
- `updatedAt: DateTimeImmutable`

## Правила (из доменной модели)

- Проект **должен иметь владельца** (`ownerId > 0`)
- `name` не может быть пустым (после trim)
- `ownerId` не может быть нулевым/отрицательным
- Immutable: изменение полей через методы, возвращающие новый экземпляр
