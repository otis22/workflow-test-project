# PRD: 2.9 — Use case AddComment

## Цель

Добавление комментария к задаче. Правило: автор — участник проекта задачи.

## Зависимости

- `App\Domain\Task\CommentRepository`:
  - `save(Comment $comment): Comment`
  - `listByTask(int $taskId): list<Comment>`
- Existing: TaskRepository, ProjectMemberRepository, Clock

## Контракт

```php
final readonly class AddComment
{
    public function execute(int $taskId, int $authorId, string $body): Comment;
}
```

### Правила

- Task существует → `TaskNotFoundException`
- Author — участник проекта задачи → иначе `NotAProjectMemberException`
- body не пустой (валидация в конструкторе Comment)
- createdAt из Clock

## Тесты

- Happy path
- Unknown task
- Author не участник
- Empty body → InvalidArgumentException (domain)
