# PRD: 2.5 — Use case CreateTask

## Цель

Создание задачи в проекте. Правило: создатель должен быть участником проекта. Опциональный исполнитель также обязан быть участником.

## Зависимости

- `App\Domain\Task\TaskRepository`:
  - `findById(int $id): ?Task`
  - `save(Task $task): Task`
  - `listByProject(int $projectId, ?Status $status = null, ?DateTimeImmutable $dueBefore = null): list<Task>`
  - `listByAssignee(int $userId): list<Task>`
- Existing: ProjectRepository, ProjectMemberRepository, Clock

## Контракт CreateTask

```php
final readonly class CreateTask
{
    public function execute(
        int $projectId,
        int $creatorId,
        string $title,
        string $description,
        Status $status,
        Priority $priority,
        ?int $assigneeId,
        ?DueDate $dueDate,
    ): Task;
}
```

### Правила

- Проект существует → иначе `ProjectNotFoundException`
- Creator — участник проекта → иначе `NotAProjectMemberException`
- Если assigneeId задан → тоже должен быть участником → иначе `NotAProjectMemberException`
- Status/Priority/DueDate — типизация на уровне enums/VO (валидация в конструкторе Task)

## Тесты

- Happy path (с assignee и без)
- ProjectNotFound
- Creator не участник
- Assignee не участник
- Timestamps из Clock
