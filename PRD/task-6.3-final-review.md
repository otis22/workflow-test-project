# PRD: Task 6.3 Final review

## Goal

Run the required final review across the MVP artifacts, architecture, security posture, CI stability, and dependency state before the closing smoke test and final changelog.

## Acceptance Criteria

- The review explicitly covers artifact alignment, architecture, security, CI/infrastructure, and dependencies according to `AGENTS.md`.
- Any documentation drift discovered during the review is corrected immediately within the task.
- Any implementation issue discovered during the review is either fixed inside the task if it is trivial or added to `Roadmap.md` as a `[review]` task in the shared queue.
- The review outcome is recorded in `AssumptionLog.md`, and `Roadmap.md` reflects the completed review task.
