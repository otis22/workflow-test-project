# PRD: 2.3 — Use case CreateProject

## Цель

Создание проекта с автоматическим добавлением владельца как участника (правило домена).

## Зависимости

- `App\Domain\Project\ProjectRepository`:
  - `findById(int $id): ?Project`
  - `save(Project $project): Project`
- `App\Domain\Project\ProjectMemberRepository`:
  - `findByProjectAndUser(int $projectId, int $userId): ?ProjectMember`
  - `save(ProjectMember $member): ProjectMember`
- `App\Domain\User\UserRepository` (existing, для проверки owner существует)
- `App\Application\Clock\Clock` (existing)

## Контракт

```php
final readonly class CreateProject
{
    public function execute(int $ownerId, string $name, string $description): Project;
}
```

### Правила

- `ownerId` должен существовать в `UserRepository`. Иначе `OwnerNotFoundException`.
- `name` валидируется конструктором Project (не пустой).
- Проект сохраняется, получает id.
- ProjectMember для владельца создаётся и сохраняется с тем же timestamp.

## Тесты

- Happy path: возвращает Project, он сохранён, владелец добавлен в participants
- Несуществующий owner → OwnerNotFoundException
- Пустой name → InvalidArgumentException (domain)
- Владелец действительно становится участником (findByProjectAndUser возвращает member)
