## Scope

### 1. `GET /tasks/{task}` — `TasksController::show`
- `auth.session` middleware.
- `TaskRepository::findById($taskId)` → 404 если null.
- Проверяет membership через existing `ListTaskComments` call: если бросает `NotAProjectMemberException` → 404.
- Рендерит `tasks/show.blade.php` с `$task`, `$comments`, `$project` (нужен для back link).

### 2. `POST /tasks/{task}/comments` — `TasksController::storeComment`
- Валидация: body required|string|max:5000 (inline в контроллере или через FormRequest).
- Вызывает `AddComment::execute($taskId, $actorId, $body)`.
- `TaskNotFoundException` / `NotAProjectMemberException` → 404.
- Redirect back to `route('tasks.show', $task)`.

### 3. View `resources/views/tasks/show.blade.php`
- Заголовок: task title, status/priority/due_date badges.
- Description.
- Блок «Comments» — список comment.body + comment.createdAt.
- Форма POST add comment с textarea + submit.
- Back link → `route('projects.show', $task->projectId)`.

### 4. Routes
```php
Route::get('/tasks/{task}', [TasksController::class, 'show'])->whereNumber('task')->name('tasks.show');
Route::post('/tasks/{task}/comments', [TasksController::class, 'storeComment'])->whereNumber('task')->name('tasks.comments.store');
```

### 5. Project show обновление
`projects/show.blade.php` — task title в списке станет ссылкой на `route('tasks.show', $task->id)`.

### 6. Feature тесты — `tests/Feature/Web/ShowTaskTest.php`
- Guest redirect.
- 404 on unknown task.
- 404 on non-member.
- Shows task fields.
- Shows comments.
- Adds a comment and redirects back.
- Rejects empty comment body.
- Project show task titles link to task show.
