# PRD 4.1 — Layout и базовые Blade-компоненты

## Источник
Roadmap 4.1 — первая задача этапа Web/UI. Фундамент для последующих страниц (4.2 регистрация, 4.3 вход, 4.4 logout, 5.x проекты, 6.x задачи, 7.x dashboard).

## Цель
Создать единый базовый layout и набор переиспользуемых Blade-компонентов, на которые будут опираться все последующие экраны MVP. Визуально минимальный, но аккуратный (ui-spec §1).

## Scope

### 1. Базовый layout — `resources/views/layouts/app.blade.php`
- DOCTYPE, `<html lang>`, viewport meta.
- `<title>` из `config('app.name')` плюс опциональный `$title` slot/variable.
- Tailwind через `@vite(['resources/css/app.css'])` — уже настроен.
- Шапка: `<x-nav />` (брэнд + навигационные ссылки).
- `<main>` со слотом `{{ $slot }}` (используется stack layout Blade component).
- Минимальный footer (копирайт/версия).

Формат — **Blade component** `x-layouts.app` (не @extends), т.к. это идиоматично для Blade 10+ и упрощает composition.

### 2. Анонимные компоненты

**`resources/views/components/nav.blade.php`** — навигация
- Брэнд «TaskFlow» слева (ссылка на `/`).
- Справа: для `@guest` — «Sign in», «Register» (placeholder href="#"); для `@auth` — «Dashboard», «Projects», «Logout» (placeholder href="#").
- Placeholder href'ы заменятся реальными route()-вызовами в 4.2–4.4 и 5.1.

**`resources/views/components/button.blade.php`** — primary/secondary кнопка
- Принимает `$variant = 'primary'` (значения: `primary`, `secondary`).
- `{{ $attributes->merge(['class' => '...']) }}` для добавления пользовательских классов/атрибутов.
- Рендерит `<button>` с Tailwind классами.

**`resources/views/components/form-field.blade.php`** — labeled form field wrapper
- Принимает `$label`, `$name`, опциональный `$error`.
- Рендерит label + `{{ $slot }}` (input идёт внутри) + сообщение об ошибке под полем.

### 3. Главная страница — `resources/views/welcome.blade.php`
- Заменить дефолтный Laravel welcome на минимальный guest landing внутри layout: брэнд, заголовок «TaskFlow», краткое описание, две кнопки «Sign in» / «Register» (placeholder href).
- Страница должна быть доступна как `@guest`, так и `@auth`, но UI в первую очередь для гостя.

### 4. Feature тест — `tests/Feature/Web/LayoutTest.php`
- `it('renders the home page with layout and nav')` — GET `/` → 200, HTML содержит «TaskFlow» (брэнд), «Sign in», «Register».
- `it('includes Tailwind-built assets via vite directive')` — смотрит, что `<link rel="stylesheet"` или ссылка на `/build/assets/` присутствует в рендере (vite directive сработал).

### Вне scope
- Реальные маршруты логина/регистрации/dashboard (4.2–7.x).
- JavaScript interactivity.
- Dark mode, responsive breakpoints beyond default, a11y-audit.
- Компоненты, которые потребуются только в этапах 5.x–7.x (например карточка проекта, список задач) — они будут добавлены там.
