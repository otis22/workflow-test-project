# PRD: 0.6 — Структура каталогов для чистой архитектуры

## Цель

Создать каталоги для слоистой архитектуры согласно требованиям секции 2 тех.требований. Настроить PSR-4 autoload.

## Структура

```
app/
├── Domain/              # Доменный слой: сущности, value objects, правила
├── Application/         # Use cases, команды, запросы
├── Infrastructure/      # Репозитории Eloquent, внешние интеграции
└── Http/                # Laravel web/UI слой (controllers, requests, resources)
```

## Требования

- Все 4 каталога созданы с `.gitkeep`
- `composer.json` autoload обновлён: App\Domain\, App\Application\, App\Infrastructure\ (Http уже есть)
- `composer dump-autoload` проходит без ошибок
- PHPStan и все проверки продолжают работать
- Никаких классов пока — только структура
