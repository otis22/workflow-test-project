# PRD: 2.7 — Use case ListProjectTasks

## Цель

Вернуть задачи проекта с опциональной фильтрацией по статусу и дедлайну.

## Контракт

```php
final readonly class ListProjectTasks
{
    public function __construct(private TaskRepository $tasks) {}

    /** @return list<Task> */
    public function execute(
        int $projectId,
        ?Status $status = null,
        ?DateTimeImmutable $dueBefore = null,
    ): array;
}
```

- Делегат к `TaskRepository::listByProject($projectId, $status, $dueBefore)`.
- Repository уже реализует фильтрацию (InMemory и будущая Eloquent).
- Задачи без дедлайна не включаются если задан `dueBefore`.

## Тесты

- Возвращает все задачи проекта без фильтров
- Фильтр по status
- Фильтр по dueBefore (исключает без dueDate)
- Комбинированный фильтр
- Не возвращает задачи других проектов
- Стабильный порядок (из репозитория)
