# PRD: 2.2 — Use cases Login и Logout

## Цель

Application use cases для входа и выхода. Без зависимостей от Laravel session/auth.

## Зависимости

- `App\Application\Auth\SessionGuard` — порт для управления сессией:
  - `login(int $userId): void`
  - `logout(): void`
  - `currentUserId(): ?int`
- `App\Domain\User\UserRepository` (existing)
- `App\Application\Hashing\PasswordHasher` (existing)

## Контракт Login

```php
final readonly class Login
{
    public function __construct(
        private UserRepository $users,
        private PasswordHasher $hasher,
        private SessionGuard $session,
    ) {}

    public function execute(string $email, string $plainPassword): User;
}
```

### Правила

- `findByEmail` → если null, бросаем `InvalidCredentialsException`.
- `PasswordHasher::verify` → если false, бросаем `InvalidCredentialsException`.
- При успехе вызываем `SessionGuard::login($user->id)` и возвращаем User.
- Сообщение исключения одинаковое для "user not found" и "wrong password" — не утечь информацию о существовании пользователя.

## Контракт Logout

```php
final readonly class Logout
{
    public function __construct(private SessionGuard $session) {}

    public function execute(): void;
}
```

- Просто делегирует `SessionGuard::logout()`. Нет проверки "залогинен ли" — logout идемпотентен.

## Тесты Login

- Успешный логин: возвращает User, сессия установлена
- Несуществующий email → InvalidCredentialsException
- Неверный пароль → InvalidCredentialsException
- Сообщения исключений идентичны (no user enumeration)
- При неудаче сессия не устанавливается

## Тесты Logout

- Очищает сессию
- Идемпотентен (вызов на пустой сессии не падает)
