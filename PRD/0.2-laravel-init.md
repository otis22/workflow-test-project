# PRD: 0.2 — Инициализация Laravel-проекта

## Цель

Создать Laravel-проект внутри Docker-контейнера, настроить подключение к БД, проверить работоспособность.

## Требования

- Laravel установлен через Composer внутри app-контейнера
- .env настроен на PostgreSQL из docker-compose
- Миграции выполняются успешно
- Стартовая страница Laravel отвечает на http://localhost:8080

## Декомпозиция

### Подзадача 0.2.1: Установка Laravel
- `composer create-project laravel/laravel .` внутри контейнера
- ~10 команд

### Подзадача 0.2.2: Настройка .env
- DB_CONNECTION=pgsql, DB_HOST=db, DB_PORT=5432, DB_DATABASE/USER/PASSWORD=taskflow
- Проверка подключения: `php artisan migrate`

### Подзадача 0.2.3: Проверка работоспособности
- curl http://localhost:8080 отвечает 200
- `php artisan migrate:status` показывает выполненные миграции
