# PRD: 2.6 — Use case UpdateTask

## Цель

Редактирование задачи. Любое подмножество полей (title, description, status, priority, dueDate, assigneeId). Валидация: assignee должен быть участником проекта.

## Контракт

```php
final readonly class UpdateTask
{
    public function execute(
        int $taskId,
        ?string $title = null,
        ?string $description = null,
        ?Status $status = null,
        ?Priority $priority = null,
        bool $changeDueDate = false,
        ?DueDate $dueDate = null,
        bool $changeAssignee = false,
        ?int $assigneeId = null,
    ): Task;
}
```

**Замечание про nullable поля:** `dueDate` и `assigneeId` в Task могут быть null. Использовать `null` как "не менять" плохо, т.к. нельзя отличить от "очистить". Поэтому отдельные флаги `changeDueDate`/`changeAssignee` — если true, передаём новое значение (возможно null), если false — оставляем старое.

### Правила

- Task существует → иначе `TaskNotFoundException`
- Если меняется assigneeId на значение ≠ null — новый assignee должен быть участником проекта → иначе `NotAProjectMemberException`
- updatedAt из Clock::now()
- Использует with* мутаторы Task

## Тесты

- Изменяет title
- Изменяет status
- Изменяет priority
- Устанавливает dueDate (changeDueDate=true, значение)
- Очищает dueDate (changeDueDate=true, null)
- Устанавливает assignee (только если участник)
- Очищает assignee (changeAssignee=true, null)
- Rejects non-member assignee
- Rejects unknown task
- updatedAt обновляется
- При отсутствии изменений возвращает task с новым updatedAt (или без изменений — обсудить)
