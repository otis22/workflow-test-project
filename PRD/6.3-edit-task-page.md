**Существующий use case** `UpdateTask::execute(actorId, taskId, ?title, ?description, ?status, ?priority, changeDueDate, ?dueDate, changeAssignee, ?assigneeId)` — partial update с boolean flags для nullable полей.

## Архитектурные решения (§13)

- **Assignee**: по-прежнему откладывается. ListProjectMembers use case и UserRepository::findByIds не существуют. Форма edit покажет assignee как readonly текстовый display, не select. Деферим полный assignee picker в backlog.
- **changeDueDate / changeAssignee flags**: form всегда передаёт все поля; changeDueDate = true всегда (форма контролирует due_date); changeAssignee = false (не трогаем).

## Scope

### 1. `GET /tasks/{task}/edit` — `TasksController::edit`
- Fetch task by id + membership check via ListTaskComments (reuse show pattern) → 404.
- Рендерит `tasks/edit.blade.php` с `$task`, `$project`, `$statuses`, `$priorities`.

### 2. `POST /tasks/{task}` — `TasksController::update` (POST т.к. HTML-формы не поддерживают PUT)
- Использует `@method('PUT')` в форме, Laravel обрабатывает как PUT.
- `UpdateTaskRequest` FormRequest: title required|trim|max:255, description nullable, status required|in:enum, priority required|in:enum, due_date nullable|date.
- Вызывает `UpdateTask::execute` с `changeDueDate: true`, `changeAssignee: false`.
- Exceptions → 404.
- Redirect to `route('tasks.show', $task)`.

### 3. Routes
```php
Route::get('/tasks/{task}/edit', ...)->name('tasks.edit');
Route::put('/tasks/{task}', ...)->name('tasks.update');
```

### 4. Task show update
`tasks/show.blade.php` — «Edit» link to `route('tasks.edit', $task->id)`.

### 5. Feature тесты — `tests/Feature/Web/EditTaskTest.php`
- Guest redirect.
- 404 non-member.
- Shows edit form pre-filled with current values.
- Updates task and redirects to show.
- Rejects empty title.
- Changes status from todo to done.
- Clears due_date (changeDueDate = true, value empty).
