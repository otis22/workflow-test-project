# PRD: Task 5.1 My tasks dashboard section

## Goal

Turn the dashboard from a placeholder shell into a personal work overview that surfaces the current user's assigned tasks, near-term deadlines, and quick project links.

## Acceptance Criteria

- The dashboard shows a "My work" section with tasks assigned to the authenticated user.
- The assigned-task section prioritizes active work and does not list completed tasks.
- The dashboard shows an "Upcoming deadlines" section with the current user's due tasks ordered by nearest deadline first.
- The deadlines section only shows near-term due tasks assigned to the authenticated user.
- The dashboard shows project quick links so the user can jump into project workspaces.
- Automated feature tests cover the main dashboard data slices and access filtering.
