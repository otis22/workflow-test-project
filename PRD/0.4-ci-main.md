# PRD: 0.4 — CI основной пайплайн

## Цель

GitHub Actions workflow, запускающийся на каждый push/PR. Все обязательные инструменты качества (секция 7.1 тех.требований) выполняются в едином пайплайне.

## Требования

- Workflow в `.github/workflows/ci.yml`
- Триггеры: `push` на все ветки и `pull_request` на main
- Job запускает: install → format:check → stan → rector:check → md → test (с coverage) → composer audit
- Сервис PostgreSQL для тестов
- PHP 8.3 + pcov
- Fail-fast: любой падающий шаг валит пайплайн

## Декомпозиция

### Подзадача 0.4.1: Базовый workflow
- Файл `.github/workflows/ci.yml`
- Setup PHP 8.3 + pcov
- Service container postgres:16
- Composer install с кэшем
- ~80 строк

### Подзадача 0.4.2: Шаги проверок
- Pint check, PHPStan, Rector dry-run, PHPMD, Pest + coverage, composer audit
- Каждый шаг — отдельный `run:` для видимости в UI GitHub Actions

### Подзадача 0.4.3: Проверка локально через act (опционально, если act установлен)
- Иначе — визуальная проверка YAML и пуш-проверка на GitHub
