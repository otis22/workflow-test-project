# PRD: 1.1 Инициализация Laravel-проекта

## Цель

Создать Laravel-приложение с архитектурной структурой каталогов, разделяющей domain, application, infrastructure и web слои согласно техническим требованиям.

## Контекст

- Стек: PHP 8.3+, Laravel (technical-requirements, секция 1)
- Архитектура: чистая архитектура с pragmatic Laravel-structure (technical-requirements, секция 2)
- Слои: domain, application, infrastructure, web/UI (technical-requirements, секция 2)

## Декомпозиция

### Подзадача 1.1.1: Создать Laravel-проект

- Установить Laravel через Composer
- Убедиться что PHP 8.3+ используется
- Проверить что проект запускается локально

### Подзадача 1.1.2: Настроить структуру каталогов

- Создать `app/Domain/` — доменная логика (сущности, value objects, правила)
- Создать `app/Application/` — use cases / application services
- Создать `app/Infrastructure/` — репозитории, внешние сервисы
- Сохранить стандартный `app/Http/` как web/UI слой
- Добавить `.gitkeep` в пустые директории

### Подзадача 1.1.3: Базовая конфигурация

- Настроить `.env.example` для локальной разработки
- Убедиться что `composer.json` имеет autoload для новых namespace
- Проверить что `artisan` работает корректно
