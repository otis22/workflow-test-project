# PRD: 2.2–2.6 Доменные сущности

## Цель

Создать оставшиеся доменные сущности и бизнес-правила.

## Сущности

- 2.2 Project (id, owner_id, name, description) + правило владельца
- 2.3 ProjectMember (project_id, user_id) + автодобавление владельца
- 2.4 Task (id, project_id, creator_id, assignee_id, title, description, status, priority, due_date)
- 2.5 Comment (id, task_id, author_id, body)
- 2.6 Доменные правила валидации

## Декомпозиция

### Подзадача: Создать сущности и value objects

- TaskStatus enum (todo, in_progress, done)
- TaskPriority enum (low, medium, high)
- Project, Task, Comment domain entities
- Правила: создатель — участник, исполнитель — участник, комментатор — участник

### Подзадача: Unit тесты

- Тесты для каждой сущности и каждого бизнес-правила
