# PRD 6.1 — Создание задачи

## Источник
Roadmap 6.1. Зависит от 5.3 (страница проекта).

## Контекст из артефактов

**`artifacts/ui-spec-taskflow-ru.md` §3 Форма задачи:**
- Позволяет: задать название, описание, выбрать статус, приоритет, указать дедлайн, назначить исполнителя, сохранить.

**`artifacts/prd-taskflow-ru.md` §5:**
- «Создание задачи внутри проекта.»

**Существующий use case** `App\Application\Task\CreateTask::execute(...)`:
- Параметры: `projectId, creatorId, title, description, Status, Priority, ?assigneeId, ?DueDate`.
- Требует project exists + creator is member + (if assigneeId set) assignee is member.
- Бросает `ProjectNotFoundException`, `NotAProjectMemberException`.

## Архитектурные решения (§13 автономность)

- **Assignee отложен в 6.3 (edit task)**: для select-списка нужен list project members → list User entities. Ни такого use case, ни метода `listByProject` на `ProjectMemberRepository` пока нет. Добавление выходит за scope 6.1. Form передаёт `assigneeId: null`. UI-spec говорит «назначить исполнителя» для формы задачи — это покрывается в 6.3 где будет edit task form.
- **DueDate**: optional date input. Значение парсится как `new DueDate(new DateTimeImmutable($value))` если заполнено.
- **Status и Priority**: select с предустановленными вариантами из enum. Default: Todo / Medium.
- **Перенаправление после создания**: redirect на `projects.show` с id проекта.

## Scope

### 1. `GET /projects/{project}/tasks/create` — `TasksController::create`
- `auth.session` middleware.
- Принимает `int $project`.
- Проверяет membership через `ShowProject::execute($actorId, $project)` — если нет доступа → 404.
- Рендерит `resources/views/tasks/create.blade.php` с `$project`, `$statuses`, `$priorities`.

### 2. `POST /projects/{project}/tasks` — `TasksController::store`
- `CreateTaskRequest` FormRequest: title required|string|max:255, description nullable|string|max:5000 (+ prepareForValidation trim на title per 5.2 precedent), status required|in:todo,in_progress,done, priority required|in:low,medium,high, due_date nullable|date.
- Вызывает `CreateTask::execute` с actorId как creatorId, assigneeId null, dueDate from input.
- `ProjectNotFoundException` / `NotAProjectMemberException` → abort(404).
- Успех: redirect на `route('projects.show', $project)`.

### 3. View `resources/views/tasks/create.blade.php`
- Внутри `<x-layouts.app>`.
- Форма POST `/projects/{project}/tasks` с CSRF.
- Поля: Title (input text), Description (textarea), Status (select), Priority (select), Due date (input date, optional).
- Submit + Cancel → projects.show.

### 4. Routes
```php
Route::get('/projects/{project}/tasks/create', [TasksController::class, 'create'])
    ->whereNumber('project')
    ->name('tasks.create');
Route::post('/projects/{project}/tasks', [TasksController::class, 'store'])
    ->whereNumber('project')
    ->name('tasks.store');
```

### 5. Show project обновление
`projects/show.blade.php` — placeholder «Create task» → `route('tasks.create', $project->id)`.

### 6. Feature тесты — `tests/Feature/Web/CreateTaskTest.php`
- Guest redirect.
- 404 on non-member project.
- Shows form for member.
- Creates task and redirects to project show page.
- Rejects empty title.
- Rejects whitespace-only title (trim).
- Rejects invalid status.
- Rejects invalid priority.
- Accepts null due_date.
