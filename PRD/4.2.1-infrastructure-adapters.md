# PRD 4.2.1 — Laravel-адаптеры для Clock, PasswordHasher, SessionGuard

## Источник
Roadmap 4.2 декомпозирован: 4.2.1 — инфраструктурный фундамент, 4.2.2 — сама страница регистрации. Без этих адаптеров контроллеры 4.2/4.3/4.4 не смогут инжектировать доменные use cases в Laravel DI-контейнер.

## Контекст из артефактов

**`artifacts/technical-requirements-taskflow-ru.md` §2 Архитектура:**
- Бизнес-логика не должна зависеть от UI, фреймворка и инфраструктуры.
- Минимально должны быть различимы: доменная логика, сценарии приложения, инфраструктурный слой, web/UI.

**Существующие порты** (`app/Application/`):
- `Clock\Clock::now(): DateTimeImmutable`
- `Hashing\PasswordHasher::hash(string): string`, `verify(string, string): bool`
- `Auth\SessionGuard::login(int $userId): void`, `logout(): void`, `currentUserId(): ?int`

**Существующие фейки** (`tests/Support/Fakes/`): `FakeClock`, `FakePasswordHasher`, `InMemorySessionGuard`. Контракт уже определён ими.

## Scope

### 1. `App\Infrastructure\Clock\SystemClock implements Clock`
- `now()` возвращает `new DateTimeImmutable()`.
- Зависимостей нет.

### 2. `App\Infrastructure\Hashing\LaravelPasswordHasher implements PasswordHasher`
- Делегирует `Illuminate\Contracts\Hashing\Hasher` (инжекция через конструктор).
- `hash($plain)` → `$this->hasher->make($plain)` (bcrypt по умолчанию).
- `verify($plain, $hash)` → `$this->hasher->check($plain, $hash)`.

### 3. `App\Infrastructure\Auth\LaravelSessionGuard implements SessionGuard`
- Делегирует `Illuminate\Contracts\Session\Session`.
- Ключ в сессии: `'auth.user_id'`.
- `login($userId)` → `$this->session->put('auth.user_id', $userId)` + `$this->session->migrate(true)` (регенерация session id против session fixation).
- `logout()` → `$this->session->forget('auth.user_id')` + `$this->session->invalidate()`.
- `currentUserId()` → `int|null` из `$this->session->get('auth.user_id')`.

### 4. Bindings
Расширить `App\Providers\AppServiceProvider::register`:
```php
$this->app->bind(Clock::class, SystemClock::class);
$this->app->bind(PasswordHasher::class, LaravelPasswordHasher::class);
$this->app->bind(SessionGuard::class, LaravelSessionGuard::class);
```

### 5. Feature тесты в `tests/Feature/Infrastructure/`

**`ClockTest.php`** (unit-уровень):
- `it('SystemClock::now returns a DateTimeImmutable close to current time')` — погрешность ≤2 секунды.

**`LaravelPasswordHasherTest.php`** (feature-уровень, т.к. использует Laravel Hasher):
- `it('hashes a password and verifies it')` — bcrypt pattern check.
- `it('rejects verify with wrong password')`.

**`LaravelSessionGuardTest.php`** (feature, HTTP-less с тестовой сессией):
- `it('login stores user id and currentUserId reads it back')`.
- `it('logout clears the stored user id')`.
- `it('currentUserId returns null when no one is logged in')`.

Все тесты через `app(...)` resolution — заодно проверяют bindings.

## Вне scope
- Контроллеры (4.2.2+).
- Laravel Auth facade интеграция — мы не используем её, у нас свой `SessionGuard` порт.
- `@auth` Blade directive вместо custom helper — оставим как есть, т.к. Laravel's @auth проверяет `Auth::check()`, не нашу сессию. В 4.2.2 будем использовать `session('auth.user_id')` или helper.
