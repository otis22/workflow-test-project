# PRD 3.2.5 — EloquentTaskRepository

## Источник
Roadmap 3.2. Продолжает 3.2.3/3.2.4.

## Прецедент
Симметрично EloquentProjectRepository: draft-паттерн, отдельный mapper, feature тесты.

**Новые аспекты:**
1. `Status` и `Priority` — backed string enum'ы → mapper хранит `value`, читает через `Status::from(...)`.
2. `assigneeId` nullable.
3. `dueDate` nullable `DueDate` VO → mapper читает/пишет `due_date` как DateTimeImmutable (через `$dueDate->value`).
4. Две дополнительные query-операции: `listByProject($projectId, ?$status, ?$dueBefore)` и `listByAssignee($userId)`.
5. `listByProject` должен фильтровать: по статусу (если задан), по `due_date < $dueBefore` (если задан — задачи без due_date исключаются). Сортировка по id ASC (симметрично фейку).
6. `listByAssignee` возвращает только задачи с `assignee_id = $userId`, сортировка по id ASC.

## Scope

### `TaskMapper`
- `toDomain(TaskModel): Task` — инициализация enum, VO, nullable.
- `toRow(Task): array` — plain scalars + Carbon/DateTime для due_date/timestamps.

### `EloquentTaskRepository implements TaskRepository`
- `findById`, `save` (draft-паттерн)
- `listByProject($projectId, ?$status, ?$dueBefore)`
- `listByAssignee($userId)`

### Binding в PersistenceServiceProvider.

### Feature тесты
- save new + round-trip всех полей (включая dueDate, assignee null и not null, enum)
- findById null-case
- update existing + stale-id exception
- listByProject без фильтров
- listByProject с фильтром по status
- listByProject с фильтром по dueBefore (должен исключать задачи без dueDate)
- listByAssignee
- listByAssignee возвращает пустой список для пользователя без задач
