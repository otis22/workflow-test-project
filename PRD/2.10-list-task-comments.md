# PRD: 2.10 — Use case ListTaskComments

## Цель

Вернуть список комментариев задачи.

## Контракт

```php
final readonly class ListTaskComments
{
    public function __construct(private CommentRepository $comments) {}

    /** @return list<Comment> */
    public function execute(int $taskId): array;
}
```

- Делегат к `CommentRepository::listByTask($taskId)`.

## Тесты

- Возвращает комментарии задачи в порядке id
- Пустой массив если комментариев нет
- Не возвращает комментарии других задач
