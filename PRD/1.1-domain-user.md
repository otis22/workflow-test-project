# PRD: 1.1 — Доменная сущность User

## Цель

Создать чистый доменный класс User в `app/Domain/User/User.php` — без зависимостей от Laravel/Eloquent.

## Поля

- `id: int`
- `name: string`
- `email: string`
- `passwordHash: string`
- `createdAt: DateTimeImmutable`
- `updatedAt: DateTimeImmutable`

## Правила

- Email должен быть валидным (базовая проверка через filter_var)
- Name не может быть пустым
- passwordHash не может быть пустым
- Immutable: изменение полей через методы, возвращающие новый экземпляр
