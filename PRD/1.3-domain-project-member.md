# PRD: 1.3 — Доменная сущность ProjectMember

## Цель

Создать чистый доменный класс ProjectMember в `app/Domain/Project/ProjectMember.php` — без зависимостей от Laravel/Eloquent.

## Поля

- `id: int`
- `projectId: int`
- `userId: int`
- `createdAt: DateTimeImmutable`

## Правила

- `projectId > 0`
- `userId > 0`
- ProjectMember иммутабельна и не имеет мутаторов: членство либо создаётся, либо удаляется (на уровне репозитория). Изменение полей участника не имеет смысла.

## Замечание про правило "владелец автоматически — участник"

Доменная модель утверждает: "Владелец проекта автоматически является участником". Это **invariant создания**, который реализуется на уровне application use case `CreateProject` (этап 2.3) — use case при создании проекта одновременно создаёт ProjectMember для владельца. На уровне entity это невыразимо без знания о Project, и заталкивать сюда конструкторный inject Project нарушит изоляцию.
