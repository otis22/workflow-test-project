# PRD 8.1 — Настройка Laravel Dusk

## Источник
Roadmap 8.1.

## Контекст
- Chrome 147 установлен на хосте. Docker PHP-контейнер не имеет Chrome.
- Dusk тесты будут запускаться **на хосте**, не внутри Docker. Сервер — `php artisan serve` процесс (или отдельный Docker-exposed port).
- CI: `e2e.yml` workflow на GitHub Actions с `ubuntu-latest`, Chrome предустановлен.

## Scope

### 1. Установка Dusk
```bash
composer require laravel/dusk --dev
php artisan dusk:install
```
Это создаст `tests/Browser/`, `DuskTestCase.php`, `.env.dusk.local`.

### 2. Конфигурация
- `.env.dusk.local`: `APP_URL=http://127.0.0.1:8000`, `DB_*` pointing to Docker pgsql (localhost:5432).
- `DuskTestCase`: headless Chrome, `--no-sandbox`, `--disable-gpu`.
- Dusk ChromeDriver: `php artisan dusk:chrome-driver --detect` для автоматического определения версии.

### 3. Smoke Dusk тест
`tests/Browser/SmokeTest.php`:
- `it('loads the welcome page and sees TaskFlow brand')`.

### 4. CI workflow `e2e.yml`
Реальный workflow вместо скелета:
- Checkout + PHP + Composer + Node + npm build (like ci.yml)
- PostgreSQL service container
- `php artisan dusk:chrome-driver --detect`
- `php artisan serve &` в фоне
- `php artisan dusk`

### 5. `.gitignore`
Добавить `tests/Browser/screenshots`, `tests/Browser/console`, `tests/Browser/source` (Dusk дефолтные).
