## Источник
Roadmap 4.4. Зависит от 4.2.1 (LaravelSessionGuard) и 4.3 (авторизованный пользователь, которого можно logout'нуть).

## Контекст из артефактов

**`artifacts/prd-taskflow-ru.md` §5:**
- «Аутентификация и завершение сессии.» — logout часть MVP.

**`artifacts/ui-spec-taskflow-ru.md`:**
- §2: Logout не упомянут явно как экран, но подразумевается как действие из nav.

**Существующий use case** `App\Application\Auth\Logout::execute(): void`:
- Тонкий делегат к `SessionGuard::logout()`, который в `LaravelSessionGuard` вызывает `$session->invalidate()` (flush + regenerate id).
- Идемпотентен: logout без активной сессии — no-op.

## Scope

### 1. `POST /logout` — `LogoutController::store`
- Принимает POST (не GET) — CSRF защита против выхода через подделку ссылки.
- Вызывает `Logout::execute()`.
- Редирект на `/` (временно; Dashboard нет).
- Guest path: если пользователь уже вышел (`currentUserId() === null`) — тоже редирект на `/`, логаут идемпотентен.

### 2. Routes
```php
Route::post('/logout', [LogoutController::class, 'store'])->name('logout');
```

Только POST маршрут — GET не добавляем.

### 3. Nav обновление
В `components/nav.blade.php` `@auth` branch:
- Заменить `<button type="button" disabled>Logout</button>` placeholder (из 4.1) на реальную форму:
```blade
<form method="POST" action="{{ route('logout') }}" class="inline">
    @csrf
    <button type="submit" class="text-gray-600 hover:text-gray-900">Logout</button>
</form>
```

### 4. Feature тесты — `tests/Feature/Web/Auth/LogoutTest.php`
- `it('logs out an authenticated user and redirects to home')` — login → POST `/logout` → 302 `/`, `SessionGuard::currentUserId()` → null.
- `it('is idempotent when called as a guest')` — без login → POST `/logout` → 302 `/`, без errors.
- `it('rejects logout via GET')` — GET `/logout` → 405.
- `it('nav shows a logout form when authenticated')` — login → GET `/` → HTML содержит `action="route('logout')"` и CSRF token.

## Вне scope
- Dashboard redirect (7.1).
- GET `/logout` (не нужен).
- «Log out everywhere» (multi-device) — не в MVP.
