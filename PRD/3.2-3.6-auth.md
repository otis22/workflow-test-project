# PRD: 3.2–3.6 Аутентификация

## Цель

Реализовать регистрацию, вход, выход и защиту маршрутов.

## Декомпозиция

### 3.2 Use case: регистрация
- Application service RegisterUser
- Валидация: name, email, password
- Создание пользователя в БД

### 3.3 Use case: вход и выход
- Application service LoginUser / LogoutUser
- Аутентификация через Laravel Auth

### 3.4 UI: страница регистрации
- Blade layout + форма регистрации
- Валидация, сообщения об ошибках

### 3.5 UI: страница входа
- Blade форма входа
- Редирект на Dashboard после входа

### 3.6 Middleware авторизации
- Защита маршрутов auth middleware (Laravel built-in)
- Гостевые маршруты: login, register
