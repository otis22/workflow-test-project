# PRD 5.1.2 — Список проектов

## Источник
Roadmap 5.1, продолжает 5.1.1 (EnsureAuthenticated middleware).

## Контекст из артефактов

**`artifacts/prd-taskflow-ru.md`:**
- §4 Истории: «Как пользователь, я хочу создать проект, чтобы группировать задачи.»
- §5 Функциональные требования: «Просмотр списка проектов текущего пользователя.»

**`artifacts/ui-spec-taskflow-ru.md` §3:**
- «Список проектов. Позволяет:
  - увидеть доступные проекты;
  - перейти в проект;
  - создать новый проект.»

**Существующий use case** `App\Application\Project\ListUserProjects::execute(int $userId): array<Project>`:
- Принимает `userId` (семантически = actorId: возвращает проекты где пользователь является member'ом).
- Сортировка по id ASC.
- Возвращает `list<Project>`.

## Scope

### 1. `GET /projects` — `ProjectsController::index`
- Защищён middleware `auth.session` (5.1.1).
- Получает `currentUserId()` из `SessionGuard` (не передаём через atom helper, а inject в контроллер).
- Вызывает `ListUserProjects::execute($currentUserId)`.
- Рендерит `resources/views/projects/index.blade.php` с `$projects`.

### 2. View `resources/views/projects/index.blade.php`
- Внутри `<x-layouts.app>`.
- Заголовок «Your projects».
- Если `$projects` пустой — сообщение «You have no projects yet.» + кнопка «Create project» (href placeholder `#` до 5.2).
- Иначе — список ссылок (для каждого проекта href placeholder `#` до 5.3).
- Кнопка «Create project» сверху справа.

### 3. Routes
Добавить в `routes/web.php` внутри группы middleware:
```php
Route::middleware('auth.session')->group(function (): void {
    Route::get('/projects', [ProjectsController::class, 'index'])->name('projects.index');
});
```

### 4. Nav обновление
`@signedIn` branch: `href="#"` на «Projects» заменить на `route('projects.index')`.

### 5. Feature тесты — `tests/Feature/Web/ProjectsTest.php`
- `it('redirects guests from /projects to login')` — guest → GET `/projects` → 302 `/login`.
- `it('shows empty state when user has no projects')` — login, no projects → 200, «no projects» message.
- `it('shows only the projects the user is a member of')` — 2 users, каждый со своим проектом, 1 project у первого — в response виден только он.
- `it('shows projects in stable id order')` — несколько проектов с известным порядком.
- `it('nav Projects link points to the projects index route')` — login → GET `/` → HTML содержит `href="{route}"`.
