# PRD: 1.4 — Доменная сущность Task

## Цель

Создать чистый доменный класс Task в `app/Domain/Task/Task.php` — без зависимостей от Laravel/Eloquent.

## Поля

- `id: int`
- `projectId: int`
- `creatorId: int`
- `assigneeId: ?int` (nullable — может быть без исполнителя)
- `title: string`
- `description: string` (может быть пустой)
- `status: string` — `todo` | `in_progress` | `done`
- `priority: string` — `low` | `medium` | `high`
- `dueDate: ?DateTimeImmutable` (nullable)
- `createdAt: DateTimeImmutable`
- `updatedAt: DateTimeImmutable`

## Правила

- `projectId > 0` (задача принадлежит проекту)
- `creatorId > 0`
- `assigneeId` либо `null`, либо `> 0`
- `title` не пустой (после trim)
- `status` ∈ {todo, in_progress, done}
- `priority` ∈ {low, medium, high}
- Immutable: изменения через `with*` методы

Правило "создатель — участник проекта" реализуется на уровне use case `CreateTask` (этап 2.5), потому что entity не знает про membership.

Правило "исполнитель — участник проекта" аналогично — use case `UpdateTask` (этап 2.6).

## Замечание про Value Objects

Status и Priority в 1.4 хранятся как строки с валидацией по белому списку. В задаче 1.6 они будут заменены на типизированные value objects (`Status`, `Priority`, `DueDate`).
