# PRD 2.r2.A — Actor authorization для UpdateTask и ListProjectTasks

## Источник
Codex review 2.11 (см. AssumptionLog 2.11). Roadmap `2.r2 [review]`. Решение пользователя — actor-based в application layer (см. ниже).

## Контекст: архитектурное решение
Authorization реализуется на уровне use cases через явный параметр `actorId`. Use case проверяет membership/ownership и бросает existing `NotAProjectMemberException` (то же, что используется в `CreateTask` для creator/assignee). Решение применяется ко всем 4 use cases из 2.r2; данный PRD покрывает первые 2.

## Scope (этой подзадачи)

### `App\Application\Task\UpdateTask`
- Добавить первым параметром `int $actorId`.
- Проверить, что `actorId` — участник проекта, в котором живёт задача:
  - После `findById($taskId)`, до изменений: `members->findByProjectAndUser($task->projectId, $actorId)`.
  - При отсутствии — бросить `NotAProjectMemberException::forUserAndProject($actorId, $task->projectId)`.
- Существующая инъекция `ProjectMemberRepository` уже есть — новых зависимостей не нужно.

### `App\Application\Task\ListProjectTasks`
- Добавить первым параметром `int $actorId`.
- Проверить, что `actorId` — участник `$projectId`. При отсутствии — `NotAProjectMemberException`.
- Инъецировать `ProjectMemberRepository` (новая зависимость).

## Тесты (Red → Green)

### `UpdateTaskTest`
- **Обновить существующие позитивные тесты**: первым аргументом передавать `actorId`, который зарегистрирован как член проекта.
- **Новый**: `it('rejects update when actor is not a project member')` → `NotAProjectMemberException`.

### `ListProjectTasksTest`
- **Обновить существующие позитивные тесты**: добавить `actorId` и регистрацию его как участника.
- **Новый**: `it('rejects listing when actor is not a project member')` → `NotAProjectMemberException`.

## Контракт сигнатуры

```php
// До:
UpdateTask::execute(int $taskId, ?string $title = null, ...)
// После:
UpdateTask::execute(int $actorId, int $taskId, ?string $title = null, ...)

// До:
ListProjectTasks::execute(int $projectId, ?Status $status = null, ?DateTimeImmutable $dueBefore = null)
// После:
ListProjectTasks::execute(int $actorId, int $projectId, ?Status $status = null, ?DateTimeImmutable $dueBefore = null)
```

`actorId` — первый параметр для всех use cases с авторизацией (соглашение).
