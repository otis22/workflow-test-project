# PRD: Этап 1. Базовое окружение и каркас проекта

## Контекст

Репозиторий содержит только управленческие артефакты и не содержит исполняемого приложения, локального Docker Compose окружения и CI-контура. По `AGENTS.md` дальнейшая реализация roadmap требует рабочей среды, поэтому этап 1 снимает стартовые блокеры и создаёт базу для следующих задач.

## Цель этапа

Подготовить минимально работоспособный Laravel-проект с локальным запуском через Docker Compose и обязательным базовым контуром качества, достаточным для продолжения roadmap по строгому workflow.

## Границы этапа

Входит в этап:

- инициализация Laravel-проекта;
- настройка локального окружения через Docker Compose;
- фиксация команд запуска и проверок в `README.md`;
- подключение базовых quality tools из технических требований;
- настройка базового GitHub Actions pipeline.

Не входит в этап:

- реализация предметных сущностей и бизнес-логики TaskFlow;
- пользовательские сценарии регистрации, проектов, задач и комментариев;
- полный e2e и mutation контур MVP.

## Критерии готовности

- Laravel-приложение собирается и запускается локально через `docker compose`;
- в репозитории описаны команды запуска и обязательных проверок;
- доступны базовые quality checks для форматирования, unit tests, статического анализа, rector, copy-paste detection и аудита зависимостей;
- основной GitHub Actions workflow запускает обязательные проверки;
- результат этапа можно использовать как стартовую точку для этапа 2 roadmap.

## Декомпозиция

1. Подготовить каркас Laravel-приложения и базовые конфигурационные файлы.
2. Настроить `docker compose` для приложения, веб-сервера и базы данных.
3. Подготовить базовые тестовые и quality-инструменты проекта.
4. Описать команды разработки и проверок в `README.md`.
5. Настроить основной GitHub Actions workflow для обязательных проверок.

## Ограничения на подзадачи

- Каждая подзадача должна укладываться в пределы до 2 человеко-часов или до 150 строк кода на один законченный шаг изменения.
- При превышении бюджета этап необходимо передекомпозировать до продолжения работ.
