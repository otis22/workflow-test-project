## Scope

### 1. `GET /dashboard` — `DashboardController::index`
- `auth.session` middleware.
- Вызывает `ListUserTasks::execute($actorId)` → все задачи пользователя.
- Вызывает `ListUserProjects::execute($actorId)` → проекты.
- Из задач: отделить «upcoming deadline» = задачи с dueDate, отсортировать по dueDate ASC, взять первые 5.
- Рендерит `dashboard.blade.php` с `$myTasks`, `$upcomingDeadlines`, `$projects`.

### 2. View `resources/views/dashboard.blade.php`
- 3 секции: «My tasks» (все), «Upcoming deadlines» (top 5), «My projects» (список со ссылками).
- Каждая задача — ссылка на `tasks.show`.
- Каждый проект — ссылка на `projects.show`.
- Empty states для каждой секции.

### 3. Routes
```php
Route::get('/dashboard', [DashboardController::class, 'index'])->name('dashboard');
```

### 4. Redirect updates
- `LoginController::store` → `redirect(route('dashboard'))` вместо `redirect('/')`.
- `RegisterController::store` → то же.
- `EnsureAuthenticated` middleware already uses `redirect()->guest(route('login'))` — no change needed.
- Nav `@signedIn` → Dashboard link использует `route('dashboard')` вместо `#`.

### 5. Feature тесты — `tests/Feature/Web/DashboardTest.php`
- Guest redirect.
- Shows «My tasks» for the actor (only assigned tasks).
- Shows «Upcoming deadlines» sorted by due date.
- Shows «My projects» with links.
- Empty state when no tasks/projects.
- After login redirect goes to dashboard.
