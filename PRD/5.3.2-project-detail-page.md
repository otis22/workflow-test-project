- `ShowProject::execute(actorId, projectId): Project` (5.3.1) — возвращает Project с membership check.

**Существующий `Status` enum**: `Todo`, `InProgress`, `Done`.

## Scope

### 1. `GET /projects/{project}` — `ProjectsController::show`
- Защищён `auth.session` middleware.
- Принимает `?status` query параметр (`todo|in_progress|done`).
- Получает `currentUserId()` из `SessionGuard`.
- Вызывает `ShowProject::execute($actorId, $projectId)` → `Project` или `ProjectNotFoundException`/`NotAProjectMemberException`.
- Вызывает `ListProjectTasks::execute($actorId, $projectId, $statusFilter)` → `list<Task>`.
- Exception handling:
  - `ProjectNotFoundException` и `NotAProjectMemberException` → 404 `abort(404)`. **Оба** в 404, чтобы НЕ плодить 2.r3 leak на web-слое (даже если use case его содержит). Это фикс 2.r3 только для web layer — domain layer остаётся как есть, документирую.
- Рендерит `resources/views/projects/show.blade.php` с `$project`, `$tasks`, `$activeStatus`.

### 2. View `resources/views/projects/show.blade.php`
- Внутри `<x-layouts.app>`.
- Заголовок — `$project->name`, под ним `$project->description` если не пустое.
- Панель фильтров: 4 ссылки «All / Todo / In progress / Done», active state через сравнение с `$activeStatus`.
- Кнопка «Create task» (placeholder `#` до 6.1) в header.
- Список задач: title, status, priority, дедлайн (опционально). Empty state «No tasks yet.»
- Ссылка «Back to projects» на `projects.index`.

### 3. Routes
В `auth.session` группу:
```php
Route::get('/projects/{project}', [ProjectsController::class, 'show'])
    ->whereNumber('project')
    ->name('projects.show');
```
`whereNumber('project')` — ограничивает параметр числом, чтобы `/projects/create` (не номер) не матчился здесь.

### 4. Projects index обновление
`projects/index.blade.php` — project name ссылка (placeholder `#`) → `route('projects.show', $project->id)`.

### 5. Feature тесты — `tests/Feature/Web/ShowProjectTest.php`
- `it('redirects guests from GET /projects/{id} to login')`.
- `it('returns 404 when project does not exist')`.
- `it('returns 404 when actor is not a project member')` — security check: проверяем, что НЕ видит project name.
- `it('shows the project name and description for members')`.
- `it('shows the project tasks in stable id order')`.
- `it('shows empty state when the project has no tasks')`.
- `it('filters tasks by status via query parameter')` — GET `/projects/{id}?status=todo`.
- `it('ignores invalid status query parameter')` — `?status=garbage` → показывает все задачи (не 500).
- `it('projects index links to the show page for each project')`.
