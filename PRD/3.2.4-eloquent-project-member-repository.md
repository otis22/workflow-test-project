# PRD 3.2.4 — EloquentProjectMemberRepository

## Источник
Roadmap 3.2. Продолжает 3.2.3.

## Прецедент
Симметрично 3.2.2/3.2.3 (draft-паттерн, отдельный mapper, feature тесты).

**Отличие:** у `ProjectMember` нет `updated_at` (см. AssumptionLog 1.3, 3.1). `ProjectMemberModel::$timestamps = false`. Mapper пишет только `created_at`. В model `$timestamps = false` уже настроено, что означает `save()` не будет автоматически менять created_at — mapper должен явно установить его (и при update-ветви не должен переписывать, т.к. сущность иммутабельна). Actually: ProjectMember вообще не обновляется по дизайну (нет `with*` методов, см. AssumptionLog 1.3). Паттерн draft-insert применим, update-ветвь теоретически не используется продакшн-кодом, но реализуется для симметрии и тестируется.

## Scope

### `App\Infrastructure\Persistence\Eloquent\ProjectMemberMapper`
- `toDomain(ProjectMemberModel): ProjectMember`
- `toRow(ProjectMember): array` — только `project_id`, `user_id`, `created_at`.

### `App\Infrastructure\Persistence\Eloquent\EloquentProjectMemberRepository implements ProjectMemberRepository`
- `findByProjectAndUser(int $projectId, int $userId): ?ProjectMember`
- `projectIdsForUser(int $userId): array<int>`
- `save(ProjectMember $member): ProjectMember` — draft-паттерн.
- Update-ветвь бросает `RuntimeException` на stale id — для симметрии, хотя практически не будет использоваться.
- Инъекция `ProjectMemberMapper`.

### Binding
Добавить в `PersistenceServiceProvider::register`:
```php
$this->app->bind(ProjectMemberRepository::class, EloquentProjectMemberRepository::class);
```

### Feature тесты
`tests/Feature/Infrastructure/Persistence/EloquentProjectMemberRepositoryTest.php`:
- `it('saves a new member and returns entity with assigned id')`
- `it('finds a member by project and user ids')`
- `it('returns null from findByProjectAndUser when no membership exists')`
- `it('lists project ids for a user')`
- `it('returns empty list from projectIdsForUser when user has no memberships')`
- `it('throws when saving a member with a positive id that does not exist')`
- `it('preserves createdAt as DateTimeImmutable on round-trip')`

Фикстура: user + project, затем members.
