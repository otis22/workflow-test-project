# PRD 3.3 — Фабрики и сидеры

## Источник
Roadmap 3.3. Зависимость: 3.2 (Eloquent models, все 5).

## Контекст
- Laravel дефолтный `App\Models\User` и `Database\Factories\UserFactory` — **мёртвый код** (проверено grep'ом, нигде не импортируется; ссылается на `password`, `email_verified_at`, `remember_token` — колонок, которых нет в domain-aligned users table из 3.1).
- Наши domain-aligned Eloquent-модели живут в `App\Infrastructure\Persistence\Eloquent\Model\`. Сейчас у них нет `HasFactory` трейта.
- Сидеров пока нет. `DatabaseSeeder::run()` пустой (Laravel boilerplate).

## Цель
1. Удалить мёртвый код `App\Models\User` + старый `UserFactory`.
2. Добавить `HasFactory` трейт ко всем 5 domain моделям.
3. Создать 5 фабрик в `database/factories/` для domain моделей (namespace'ы корректные).
4. Создать `DatabaseSeeder` с детерминированным сидом для локальной разработки: несколько users, проект с участниками, задачи разных статусов/приоритетов, комментарии.
5. Тест фабрик: feature тест убеждается, что каждая фабрика создаёт валидную строку (FK констрейнты держатся).

## Scope

### Удалить
- `app/Models/User.php`
- `database/factories/UserFactory.php` (старая, Laravel default)

### Добавить `HasFactory` trait
Во все 5 моделей в `app/Infrastructure/Persistence/Eloquent/Model/`:
- `UserModel`, `ProjectModel`, `ProjectMemberModel`, `TaskModel`, `CommentModel`

Laravel находит фабрики по соглашению `Database\Factories\{ModelName}Factory`. Поскольку наши модели в `Infrastructure\...\Model` namespace, нужно явно указать через `protected static string $factory = ...` property или через `newFactory()` метод. Использую `$factory` property для простоты.

### Создать фабрики в `database/factories/`
- `UserModelFactory` — `name` (fake), `email` (unique safeEmail), `password_hash` (fake)
- `ProjectModelFactory` — `owner_id` (через `UserModel::factory()`), `name`, `description`
- `ProjectMemberModelFactory` — `project_id` + `user_id` (через фабрики)
- `TaskModelFactory` — все поля, random enum
- `CommentModelFactory` — `task_id`, `author_id`, `body`

Каждая фабрика должна корректно указывать `protected $model = ...::class`.

### Создать `DatabaseSeeder`
Детерминированный сид:
- 3 пользователя (Alice, Bob, Charlie) с фиксированными email'ами
- 1 проект owner=Alice, members=[Alice, Bob] (Charlie — outsider)
- 3-4 задачи разных статусов/приоритетов
- 1-2 комментария

Должен быть идемпотентным в рамках `db:seed` (для тестов через `RefreshDatabase`).

### Feature тест
`tests/Feature/Database/FactoriesTest.php`:
- `it('creates a valid user via factory')`
- `it('creates a valid project via factory with auto-created owner')`
- `it('creates a valid project member via factory')`
- `it('creates a valid task via factory')`
- `it('creates a valid comment via factory')`
- `it('runs the DatabaseSeeder without errors and populates expected counts')`
