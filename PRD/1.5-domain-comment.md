# PRD: 1.5 — Доменная сущность Comment

## Цель

Чистый доменный класс Comment в `app/Domain/Task/Comment.php` — без зависимостей от Laravel/Eloquent.

## Поля

- `id: int`
- `taskId: int`
- `authorId: int`
- `body: string`
- `createdAt: DateTimeImmutable`

## Правила

- `taskId > 0`
- `authorId > 0`
- `body` не пустой (после trim)
- Иммутабельна. Мутаторы не нужны: комментарий либо создаётся, либо удаляется. Редактирование не входит в MVP scope (UI spec не предусматривает edit).

Правило "автор — участник проекта" реализуется в use case `AddComment` (этап 2.9).
