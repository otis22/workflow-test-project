**Существующий use case** `App\Application\Project\CreateProject::execute(int $ownerId, string $name, string $description): Project`:
- Требует ownerId существующим (`OwnerNotFoundException` иначе).
- Автоматически добавляет owner'а как `ProjectMember` (см. 2.3).
- Domain Project: `name` required (trim !== ''), `description` может быть пустой.

## Scope

### 1. `GET /projects/create` — `ProjectsController::create`
- Защищён `auth.session` middleware.
- Рендерит `resources/views/projects/create.blade.php` с формой.
- Использует уже существующий `ProjectsController` (не отдельный `CreateProjectController`) — идиоматично для resource routes.

### 2. `POST /projects` — `ProjectsController::store`
- `CreateProjectRequest` FormRequest: `name` (required, string, max:255), `description` (nullable, string, max:5000).
- Вызывает `CreateProject::execute($session->currentUserId(), $name, $description)`.
- `OwnerNotFoundException` → re-throw (500, программная ошибка: middleware уже гарантировал auth'д user).
- Успех: `redirect(route('projects.index'))` с flash-сообщением через `session()->flash('status', 'Project created.')`.

### 3. View `resources/views/projects/create.blade.php`
- Внутри `<x-layouts.app>`.
- Форма POST `route('projects.store')` с CSRF.
- Поля: Name (обязательное, input text), Description (textarea, опциональное) через `<x-form-field>`.
- `<x-button type="submit">` + «Cancel» link на `projects.index`.

### 4. Routes
Добавить в `auth.session` группу:
```php
Route::get('/projects/create', [ProjectsController::class, 'create'])->name('projects.create');
Route::post('/projects', [ProjectsController::class, 'store'])->name('projects.store');
```

Порядок важен: `/projects/create` **до** `/projects/{id}` (появится в 5.3), чтобы `create` не матчился как id.

### 5. Projects index обновление
В `projects/index.blade.php` placeholder «Create project» ссылки (две штуки: в header и в empty state) заменить на `route('projects.create')`.

### 6. Feature тесты — `tests/Feature/Web/CreateProjectTest.php`
- `it('redirects guests from GET /projects/create to login')`.
- `it('shows the create project form to authenticated users')` — 200, видит form, action, CSRF.
- `it('rejects guest POST /projects via the auth middleware')` — 302 `/login`.
- `it('creates a new project and redirects to the list')` — happy path; в БД создан project с owner + project_member с owner.
- `it('registers the creator as the first project member')` — проверяем `ProjectMemberRepository::findByProjectAndUser(projectId, ownerId)`.
- `it('rejects submission with an empty name')` — `assertSessionHasErrors('name')`.
- `it('rejects submission when name is too long')` — 256 chars → error.
- `it('accepts empty description')` — success.
