# PRD 5.3.1 — ShowProject use case

## Источник
Roadmap 5.3 декомпозирован. Для страницы проекта нужен use case, возвращающий `Project` entity с проверкой membership. В текущем application-слое есть только:
- `CreateProject` — создаёт
- `ListUserProjects` — список по user
- `ListProjectTasks` — задачи проекта (membership check внутри)

Нет пути «отдать Project по id для authorized actor». Добавляется здесь.

## Контекст из артефактов

**`artifacts/prd-taskflow-ru.md` §3, §5:**
- «Пользователь работает только со своими данными и проектами, в которых участвует.»
- §5: «Просмотр списка задач проекта» — подразумевает доступ к проекту по id.

**`artifacts/ui-spec-taskflow-ru.md` §3 Страница проекта:**
- Показывает: название проекта, список задач, фильтры по статусу.

## Scope

### `App\Application\Project\ShowProject`
- Конструктор: `ProjectRepository $projects`, `ProjectMemberRepository $members`.
- `execute(int $actorId, int $projectId): Project`:
  1. `$projects->findById($projectId)` — если null, `ProjectNotFoundException`.
  2. `$members->findByProjectAndUser($projectId, $actorId)` — если не член, `NotAProjectMemberException` (reuse из `Task\Exception`).
  3. Return `Project`.

### Exception
Создать `App\Application\Project\Exception\ProjectNotFoundException::forId(int $id): self` симметрично `OwnerNotFoundException`.

### Information disclosure заметка
Симметрично `UpdateTask`/`ListTaskComments`: существующие Codex findings 2.r3 (404 vs 403 leak) применимы и здесь. Неавторизованный actor через `ShowProject` тоже может различить «project не существует» от «нет membership». Сохраняю тот же паттерн — не меняю дизайн в этой подзадаче, оставляю оба exception'а. Если 2.r3 будет реализован, ShowProject получит тот же фикс.

### Unit тесты — `tests/Unit/Application/Project/ShowProjectTest.php`
Использует InMemory fakes (как другие unit-тесты application слоя).
- `it('returns the project when actor is a member')`.
- `it('throws ProjectNotFoundException for unknown project id')`.
- `it('throws NotAProjectMemberException when actor is not a member')` (проект существует).
- `it('checks project existence before membership (document ordering)')` — чтобы зафиксировать текущее поведение 404-before-403 (связано с 2.r3 review debt).
