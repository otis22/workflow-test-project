# PRD 3.2.6 — EloquentCommentRepository

## Источник
Roadmap 3.2. Последний из четырёх оставшихся репо в 3.2.

## Прецедент
Симметрично 3.2.4 (ProjectMember): immutable entity только с `created_at`, mapper/repo по тому же шаблону.

**Отличие от других репо:** `CommentRepository` интерфейс **не имеет** `findById` — только `save` и `listByTask`. Интерфейс минимальный.

## Scope

### `CommentMapper`
- `toDomain(CommentModel): Comment`
- `toRow(Comment): array` — `task_id`, `author_id`, `body`, `created_at`.

### `EloquentCommentRepository implements CommentRepository`
- `save(Comment): Comment` — draft-паттерн.
- `listByTask(int $taskId): array<Comment>` — сортировка по id ASC (симметрично `InMemoryCommentRepository`).
- Update-ветка сохранена для симметрии; практически не вызывается (Comment иммутабелен).

### Binding в PersistenceServiceProvider.

### Feature тесты
- save new + round-trip
- listByTask возвращает коменты по taskId, упорядоченные по id
- listByTask пустой для несуществующего task
- listByTask не возвращает комментарии из других задач
