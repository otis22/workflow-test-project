# PRD: 2.8 — Use case ListUserTasks

## Цель

Вернуть задачи, назначенные текущему пользователю (из всех проектов).

## Контракт

```php
final readonly class ListUserTasks
{
    public function __construct(private TaskRepository $tasks) {}

    /** @return list<Task> */
    public function execute(int $userId): array;
}
```

- Делегат к `TaskRepository::listByAssignee($userId)`.

## Тесты

- Возвращает задачи где пользователь — assignee
- Пустой список если нет назначенных
- Не возвращает задачи без assignee
- Не возвращает чужие
