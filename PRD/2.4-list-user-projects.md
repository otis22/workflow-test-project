# PRD: 2.4 — Use case ListUserProjects

## Цель

Вернуть список проектов, в которых пользователь является участником.

## Контракт

```php
final readonly class ListUserProjects
{
    public function __construct(
        private ProjectRepository $projects,
        private ProjectMemberRepository $members,
    ) {}

    /** @return list<Project> */
    public function execute(int $userId): array;
}
```

### Правила

- Берём список projectId из `ProjectMemberRepository::projectIdsForUser`
- Загружаем проекты через `ProjectRepository::findById`
- Пропускаем null-проекты (orphan membership — необычно, но защитно)
- Порядок: по id возрастанию (стабильный)

## Тесты

- Возвращает проекты, где пользователь участник
- Возвращает пустой массив если нет участий
- Не возвращает проекты других пользователей
- Стабильный порядок по id
